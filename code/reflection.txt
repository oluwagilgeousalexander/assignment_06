Something I learned while working on this assignment is why and how to keep an API key private. 
The API key identifies me as a user and allows me to make calls to an application, so it must stay confidential. 
In this assignment, I kept it out of any public-facing code by storing it in a .env file, which is listed in .gitignore so it is never committed.
